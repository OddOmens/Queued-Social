Meta Developer Console Checklist

Required Settings in Meta Developer Console:

  1. App Status: Must be in "Live" mode (not Development)
  2. Redirect URI: Must exactly match: https://schedule.oddomens.com/auth/threads/callback
  3. App Domains: Must include: schedule.oddomens.com
  4. Client ID: Must be: 753393784148937
  5. Scopes: Must have approved: threads_basic,threads_content_publish

⚠️ Most Common Issue:

The app is in Development mode instead of Live mode. In Development mode, only app developers can use OAuth. Switch to Live mode in the App Review section.
